# MEDHA — Intelligence of Maternal Care

### Non-Invasive Maternal EHG Monitoring | Research Prototype

MEDHA is an ongoing healthcare technology project focused on developing an affordable, non-invasive system for acquiring and analysing uterine electrical activity using Electrohysterography (EHG).

The long-term objective is to explore AI-assisted preterm birth risk assessment and support doctors with accessible monitoring data.

## Hardware Components

- ESP32-S3 microcontroller
- AD620 instrumentation amplifier modules
- ADS1115 analogue-to-digital converter
- Surface electrodes
- Supporting electronic components
